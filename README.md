# Solvely Mock Exam Experience

An interactive desktop mock-exam demo recreated from a supplied screen recording.

## Stack

- Vue 3
- TypeScript
- Vite

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The demo includes answer selection, number-key shortcuts, previous/next navigation, a 27-question navigator, mark-for-review, answer elimination, a countdown timer, text highlighting, and a draggable split pane.
